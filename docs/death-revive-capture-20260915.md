来源：代理抓包 `packet_transactions`，本地时间（Asia/Shanghai）**00:58:40 → 00:59:12**。
原始帧归档：`captures/death-revive-20260915.txt`（823 帧，含整包 hex）；
带偏移解码：`captures/death-revive-20260915.decoded.txt`（工具 `tools/decode_frames.ps1`）。

偏移口径：**整包绝对偏移**（+4 = 长度/opcode 头之后的第一个字）。

## 3. 客户端脚本（决定性证据）

`Localization/en_us/UI/XML/Revive.lua` + `ReviveUI.xml`（zh_cn 同名文件内容一致）：

```lua
local REVIVE_STONE = 0;   -- 复活石
local REVIVE_MONEY = 1;   -- 花钱
local REVIVE_FREE  = 2;   -- 免费

function OnClick_ReviveBtn_Free()
    ...
    Revive:SetReviveType(REVIVE_FREE);
end

function OnClick_Confirm()
    ...
    Revive:TimeStart();        -- 开始倒计时，倒计时结束由 C++ 发复活包
end

function Updata_ReviveTime(time)   -- 倒计时每跳一次刷新文本
    Revive_Text:SetText(time .. Get_Revive_Msg("msg60"));
end
```

也就是说：**弹窗、三个选项、倒计时全是客户端行为**，服务端只在最后收到一个 12 字节的
`10028 {对象ID, 类型}`。这与抓到的 `{1167, 2}` 完全吻合（类型 2 = 免费复活）。

## 5. 与我们的服务端对比

| 项 | 参考服（实测） | 我们服务端 | 状态 |
| --- | --- | --- | --- |
| 复活请求 opcode | `C2S 10028` | `Opcodes.Revive = 10019`（`ReviveRequest.TryParse` / `GameClientHandler.Dispatch`） | **不一致** |
| 免费复活语义 | 回城 + 落地帧 + 10% HP/MP | `RestoreFreeRevivalStateAsync`：回城 + `10%` HP/MP + 清仇恨 | 一致 ✅ |
| 落地帧编码 | `+20 = (地图<<16) \| 1`（地图 1 → `0x00010001`） | `PacketBuilder.PlayerDeath` 把 `mapId` 直接写在 +20 | 数值不同 |
| 死亡通知 | 死亡时不发落地帧；客户端靠 10026 自行判定 | 死亡时发 `10018`（28B，`PlayerDeath`） | 行为不同 |

**关键点：整个抓包库 149k 行里，`C2S 10019` 出现 0 次，`C2S 10028` 出现 1 次**
（就是这次的免费复活）。而我们服务端只在 10019 上接复活请求 → 在当前客户端上，
玩家点确认复活后服务端收不到请求，角色会一直躺着。

> 另外，`Opcodes.Revive = 10019` 这个名字本身值得怀疑：`PacketBuilder.EnterMainOpcode`
> 同时也是 `0x2723`（10019），而抓包里 10019 是登录时那条 1624 字节的 `EnterMain` 帧。

## 6. 顺带纠正的三个旧结论

- `10297` **不是**复活：客户端符号 `ConsModule::SendMsg`（ConstellationMgr.obj，星座模块）
  与 `Opcodes.Zodiac` 对应；抓到的 `C2S 10297 {obj, 0x00010000, 0,0,0,0}` 是星座操作。
- `10171` **不是**死亡通知：8 字节 `{对象ID}`，客户端在攻击/读条被打断时反复发送，
  已命名 `Opcodes.SkillCastInterrupt`。
- `10041` / `10042` **不是**血量：分别是天赋技能解锁列表（2 条）与天赋等级列表（18 条），
  只在进入世界时下发一次。

## 7. 仍未验证

- 复活石（类型 0）/ 花钱（类型 1）两条路径的服务端契约与扣费规则（抓包里没有样本）。
- 死亡对**其他玩家**的可见帧（本次是单客户端，没有旁观者视角）。
- 客户端倒计时的具体秒数（脚本只负责显示剩余秒数，常量在 exe 里）。
- `10018` 的 `+20` 字段是"地图<<16 | 1"还是"u16 地图 + u16 标记"，需要第二个地图的样本才能定死。
- **除雅典城（地图 1）以外每张地图的回城落点**：只抓到地图 1。参考服本体是远端
  （`gworiginsv.exe` 只是 Go 网关，实际游戏服在 `82.25.36.18:13333`，本地二进制里没有
  世界/回城数据），所以要补齐其它地图只能在参考服上"在目标地图死一次"，从
  `S2C 10018 (28)` 里读出该地图的落点。
