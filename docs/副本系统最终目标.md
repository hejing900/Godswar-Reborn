# 副本系统 · 最终目标（施工基准）

> 本文是运营（甲方）确认的目标与行为规格，作为后续所有改动的验收基准。
> 原则一句话：**一套流程，四家共用；各家的规则作为插件保留。**

---

## 一、最终目标（一句话）

四个副本（**飘渺幻境 / 亚特兰蒂斯 / 港湾遇袭 / 美杜莎之岛**）的**入场、提示、名单、面板、结束、离场、队长、重连、结算触发**
全部由**同一份实现**提供；各家只保留自己**独特的规则**（进入条件、地图、时限、计分、奖励表）。
以后新增副本 = 只写规则，流程自动继承。

---

## 二、可验证的验收标准（"共用"不是"看起来一样"）

1. **发送点唯一**：那几类封包（进入提示、完成四帧、清零包、名单）在全仓库**各只有一处**发送点。
2. **无残留实现**：四个副本内**不得再有各自的**名单构造、结束/终态、离场、队长判定实现（各自那份必须删空或改成一行转发）。
3. **检查通过**：全量协议检查与基线 **457 通过 / 22 失败** 逐项对比**无新增失败**；关键行为必须有**注册的**自动化检查覆盖（用同一套断言跑四家，不是每家各写一套）。
4. **实机一致**：四家在同一场景下的表现一致（由运营进游戏确认）。

---

## 三、共用部分（必须唯一实现）

| 关注点 | 内容 |
|---|---|
| 入场提示与确认 | 报名后给**全队每人**发提示（进入窗口 / 邀请）；点了才进；**不点自动消失且不扣次数**；邀请可在有效期内被接受；**超时移除** |
| 服务端拉人入场 | 确认后由服务端把成员拉进正在运行的副本（各自领各自次数） |
| 名单与状态 | 四态：**等待**（受邀/报名但未进场）、**在线**、**在线(队长)**、**离线**（进过场但掉线）；邀请过期/报名未确认且窗口已过 → **从名单移除** |
| 面板发布 | 副本内**所有人**（含后加入者）都有进度面板，显示**当前分数与剩余时间**；面板在客户端场景就绪后才发 |
| 结束 / 终态 | **手动结束 / 时限到期 / 通关**走同一套：完成四帧（当前进度 + 面板完成态 + 可离场 + **30 秒倒数**）→ **点"离开副本"立即出场**、**不点 30 秒后自动出场**（**只走点击者**）→ 结束后**清空名单** |
| 离场 | 送回本阵营主城；结算失败**不得阻塞离场** |
| 队长 | 结束权限**只认副本队长**（与组队队长无关）；队长**掉线/离场 → 自动转交给下一位在场成员**；转交后结束权限随之转移 |
| 掉线重登 | 副本镜像仍在运行且里面**还有其他人** → **回到副本入口点**并恢复面板；否则回主城 |
| 次数账本 / 空副本退役 | 沿用现有实现 |
| 结算触发 | 三种终态都触发一次结算；以副本实例为幂等键（**每次进本独立结算**） |

## 四、各家规则插件（允许且必须差异化）

| 规则 | 飘渺幻境 | 亚特兰蒂斯 | 港湾遇袭 | 美杜莎之岛 |
|---|---|---|---|---|
| 进入条件 | 各自等级/人数/每日次数/入口页 | 同左 | 50 级、≥3 人、1 次/日、208/209 分档 | 难度页、独立次数表 |
| 内容地图 / 客户端场景 | 207 / 227 | 205 / 224 | 208 或 209 / 229 或 230 | 200 或 204 / 各自 |
| 时限 | 40 分钟 | 40 分钟 | 30 分钟 | 40 分钟 |
| 通关判定 / 计分 | 8 座岛逐个清除 | 团队积分（达 850 通关） | 无（怪物由运营用 GM 工具发布） | 团队积分 3000 + 用时 |
| 奖励表 | 按岛屿逐个发称号 | **未完成 13 档就低取档**（0→200 … 700→2400）+ 完成 850→2800 与称谓 | 无奖励内容 | 未完成档 + 完成用时档 + 高级版称谓（**表已存在，不得改动**） |
| 界面附加信息 | 岛屿进度 | 分数/波次 | 无 | 难度/剩余 |
| 入场策略 | 标准 | 标准 | 标准 | **持久化入场（保留为插件，不拉平）** |

**取档规则**：一律**就低**（取"不超过当前分数/用时的最大档"）。
**在场规则**：奖励只发给**结算时仍在副本内**的角色；**掉线 = 不在场 = 不发**；已获得的进度奖励不回收。

## 五、明确不做

- **客户端零改动**（全部使用原生封包与窗口）。
- **怪物、掉落**：由运营用 GM 工具发布；服务端不生成内容（飘渺/亚特兰蒂斯/美杜莎的既有怪物逻辑保持不动）。
- **计分逻辑与每日次数上限**：不改。
- 美杜莎的持久化入场链路**不拉平**。
- 美杜莎"**入队自动邀请**"要**关掉**（入队 ≠ 邀请进副本；只保留输入角色名的手动邀请）。
