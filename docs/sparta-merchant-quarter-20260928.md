## 4b. 战场颁发者（02:54–02:56 抓包，四层菜单）

数据源：会话 `0f68525b-4b47-418a-89ac-8bb8f93d4169`，npc **5070 = `Sparta_073`**，
功能号 **3**（客户端 `NpcFunWar.lua` = `NPC_FLAG_SYS_WAR`），本地 02:54:12–02:56:14。
按前面各 NPC 的同一套做法移植：抓包取号 → 写对话定义 → 路由表按 NPC 键注册。
雅典的 `Athens_073` 是**另一个实体**（自己的外观与交互号），但背后同一个脚本，
因此用**同一份对话定义**注册（`"Athens_073" or "Sparta_073"`），两边菜单一致。

| 层 | 抓包实测 |
|---|---|
| 1（开窗页） | `[1, 2, 3, 4]` = 品都斯山 / 尼米尼山谷 / 利兰丁农场保卫战 / 帕纳萨斯山 |
| 2 | `1→[173,174,175,176]`、`2→[1967]`、`3→[71,72,73]`、`4→[215]` |
| 3 | `173/175/1967→[1755]`、`174→[3001,3002,3003]`、`176→[11763,11764,11765,11766]`、`71→[201]`、`72/73→[204]` |
| 4 | `(174) 3001/3002/3003→[1755]`；`(176) 11763→[170001,114002,100003,100004,100005,17]`、`11764→[101011,100012,100013,100014,100015,17]`、`11765→[100011,…,100015,-83]`、`11766→[184022,405021]` |

**为什么必须按层索引**：`3001-3003` 与 `11763-11766` 既是第 3 层的**应答**，又是第 4 层的
**按钮号**；客户端在第 4 层点击时把页号留在 `+20`、把选中的号放进第一个参数词，
平表会把它当成第 3 层的页号再发一遍（即“各级重叠”）。因此
`ScriptedNpcDialogue` 增加可选的 `PageSelections[页号][按钮号]`，分派时**先查这一对**，
再退回原来的单层 `Steps`。不填该字段的 NPC 行为逐字节不变。

标注：抓包这一轮该角色**没参加战场**，所以 `1755`（“你没参加战场活动不能领取奖励!”）
与第 4 层各结果都是参考服当时真实下发的行；本移植只回显这些行，不做奖励发放。
